### ⚡ Now shipping

**[i18n-audit](https://github.com/Julia-IO/i18n-audit)**: a zero-dependency i18n linter. It catches hardcoded strings, sentences glued together from pieces and hand-rolled plurals, and checks translations for missing keys and broken placeholders. Works with React, Vue, Svelte and Flutter.

```bash
npx github:Julia-IO/i18n-audit ./your-app
```

**[echocraft-locales](https://github.com/Julia-IO/echocraft-locales)**: zero-touch localization. Claude Code agents translate and audit UI strings on every PR, and a terminology ontology served over MCP keeps them consistent. Humans review; they don't write strings.

**[ai-education-resources](https://github.com/Julia-IO/ai-education-resources)**: free, game-style classroom sessions for ages 12–16 that run in any browser, licensed CC BY 4.0.
▸ [Level Up: AI & You](https://julia-io.github.io/ai-education-resources/Sessions/Level-Up-AI-and-You.html) ▸ [Level Up 2: How Apps Really Work](https://julia-io.github.io/ai-education-resources/Sessions/Level-Up-2-How-Apps-Really-Work.html)

**[playshelf](https://playshelf.org)**: playful educational games and creative tools. Free for kids and families.

### 🧊 Building

**[Black Ice](https://black-ice.ai)**: semantic governance for multilingual AI pipelines. It keeps terminology, register and market rules consistent across LLM workflows.
